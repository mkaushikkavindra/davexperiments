# Data Analytics and Visualization Lab

## CS4503 – Data Analytics and Visualization

This repository contains the implementations of the **Data Analytics and Visualization (DAV) Laboratory** experiments using Python, Jupyter Notebook, Google Colab, and various data analysis and visualization libraries.

The experiments cover data handling, statistical analysis, data visualization, hypothesis testing, regression, classification, and time series analysis.

### Experiment 4 – Data Visualization and Hypothesis Testing

#### 4A – Normal Curves

Visualization of numerical attributes using:

- Histograms
- KDE curves
- Normal distribution curves

#### 4B – Z-Test

A Z-test is performed on glucose levels to determine whether the mean differs significantly from a specified population mean.

#### 4C – T-Test

Independent T-tests are performed on:

- Glucose
- Blood Pressure
- BMI

#### 4D – ANOVA

One-way ANOVA is performed to analyze differences between dataset groups.
